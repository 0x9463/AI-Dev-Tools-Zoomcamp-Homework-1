# Task-grooming template

Use the following sections in the GitHub issue body. Replace the guidance with issue-specific content. Keep Out of Scope brief; use "No additional exclusions" when none need stating. Omit Open Questions when there are none.

## Goal

State the user outcome this issue should achieve in one or two sentences.

## Context / Description

Describe the relevant context and expected user-facing behavior. Preserve necessary references, prerequisites, and established decisions without prescribing technical implementation.

## Acceptance Criteria

- [ ] Given [relevant condition], when [action or event], [observable outcome].
- [ ] [Add objectively checkable outcomes for important edge cases within scope.]

## Out of Scope

List nearby behavior this issue does not include, where needed to prevent ambiguity or scope expansion.

## Open Questions

List unresolved product questions that need answers before the affected behavior can be implemented. Do not treat assumptions as agreed requirements.
